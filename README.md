## Overview

LaunchForge is a lightweight Windows system tray application that helps you launch complete workflows using a single keyboard shortcut.

Instead of manually opening the same applications every time you start working, gaming, or creating content, LaunchForge allows you to create custom app groups and launch them instantly.

Whether it's your work setup, gaming setup, or editing setup, one shortcut is all you need.

---

## Features

### • Multi-App Launcher

Launch multiple applications simultaneously using a single keyboard shortcut.

Examples:

- VS Code + Chrome + Terminal
- Photoshop + Lightroom + Spotify
- Steam + Discord + MSI Afterburner

---

### • Global Keyboard Shortcuts

Create custom global hotkeys that work from anywhere in Windows.

No need to search through the Start Menu or keep dozens of desktop shortcuts.

---

### • Workflow Profiles

Organize different shortcuts into separate profiles.

Examples:

- Work
- Gaming
- Content Creation
- Development
- Personal

Switch between profiles anytime from the system tray.

---

### • Smart Application Detection

LaunchForge automatically detects applications installed on your system, including:

- Desktop applications
- Start Menu applications
- Hidden Windows applications
- Applications without easily accessible executable files

You don't need to manually browse through system folders to locate executable files.

---

### • System Tray Integration

LaunchForge runs silently in the background.

The tray menu provides quick access to:

- Settings
- Manage Key Bindings
- Switch Profiles
- Exit

No unnecessary windows stay open while working.

---

### • Lightweight

Designed to consume minimal system resources.

LaunchForge is intended to stay running in the background without affecting system performance.

1. Launch LaunchForge
2. Configure your shortcuts
3. Minimize to the system tray

## Known Issues

### Administrator Permissions

Some applications require Administrator privileges.

If those applications do not launch correctly, run LaunchForge as Administrator.

---

### Shortcut Conflicts

Some keyboard shortcuts are already reserved by Windows or other applications.

If a shortcut doesn't work, choose a different key combination.

---

### Antivirus Warning

Applications built with PyInstaller may occasionally trigger antivirus warnings.

This is a common false positive and does **not** indicate malicious software.

---

### Startup Delay

When Windows starts, LaunchForge may require a few seconds before global shortcuts become active.

---

## Troubleshooting

### Shortcut isn't working

- Verify the shortcut isn't already used by Windows.
- Restart LaunchForge.
- Try running as Administrator.

---

### Application isn't launching

- Remove and re-add the application.
- Verify the application is installed correctly.
- Check whether the application requires Administrator privileges.

---

### Tray icon is missing

Expand the Windows **Show hidden icons** menu.

If necessary, restart LaunchForge.
