## ⚡ About LaunchForge

**LaunchForge** is a lightweight Windows system tray application that allows you to launch multiple apps with a single shortcut.

No more searching apps. No more desktop clutter.  
Just press a key — and your entire setup is ready.

---

## 🔥 Features

### 🎯 Multi-App Launcher
- Launch multiple apps with a single key
- Set custom delays between app launches
- Perfect for daily workflows

---

### ⌨️ Custom Key Bindings
- Create your own keyboard shortcuts
- Global hotkey support
- Works anywhere in the system

---

### 🧠 Profile System
- Create multiple profiles:
  - Work 💼
  - Gaming 🎮
  - Creator 🎥
- Switch profiles instantly from system tray

---

### 🔍 Smart App Detection
- Detects:
  - Installed apps
  - Start Menu apps
  - Hidden/system apps
- No need to manually find `.exe` files

---

### 🖥️ System Tray App
- Runs in background
- Accessible from system tray ("Show hidden icons")
- Tray menu options:
  - Settings
  - Manage Key Bindings
  - Switch Profile
  - Exit

---

### 🪶 Lightweight
- Low RAM usage
- Fast and responsive
- Runs continuously in background

---

## 💻 Compatibility

- ✅ Supported: Windows 64-bit  
- ❌ Not Supported: Windows 32-bit, macOS, Linux , Arm64

> ⚠️ LaunchForge is currently built only for **Windows (64-bit)** systems.  
Support for other platforms may be added in future releases.

## 📦 Installation

### 🔽 Download Installer

1. Go to the **Releases** section of this repository
2. Download `LaunchForge-Setup.exe`
3. Run the installer
4. Launch the app 🚀

---

## 🧪 How to Use

1. Open LaunchForge from system tray  
2. Add a new key binding  
3. Select apps you want to launch  
4. Assign a shortcut  
5. Press the shortcut and enjoy ⚡  

---

## ⚠️ Known Issues

### 🔸 Admin Permission
Some apps may require LaunchForge to run as Administrator

---

### 🔸 Hotkey Conflicts
If a shortcut is already used by Windows or another app, it may not work

---

### 🔸 Antivirus Warning
Some antivirus tools may flag the `.exe` (common for PyInstaller/Inno Setup apps)  
This is a false positive

---

### 🔸 Startup Delay
App may take a few seconds after system boot to become active

---

## 🛠️ Troubleshooting

### ❓ Hotkeys not working?
- Run app as Administrator  
- Try a different key combination  

---

### ❓ Apps not launching?
- Re-add the app  
- Check if the app exists  
- Try running manually once  

---

### ❓ Tray icon not visible?
- Check "Show hidden icons" in Windows tray
